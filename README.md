# Novaula

Piattaforma di classe: materiali, programma, compiti, verifiche, chat e sportello «Aiuto».
Sito statico (cartella `sito/`) + Supabase. Ogni push su `main` viene pubblicato su https://novaula.netlify.app.

- `sito/` — il sito pubblicato
- `setup.sql` — schema iniziale del database
- `aggiornamenti/` — aggiornamenti del database da eseguire nel SQL Editor di Supabase
- `SETUP.md` — guida all'installazione
