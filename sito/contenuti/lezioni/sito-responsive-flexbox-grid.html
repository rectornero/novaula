Laboratorio:
CineTerza responsive

Costruiamo da zero il sito del cineforum di classe: Flexbox per i pezzi piccoli, Grid per l'impaginazione, mobile first dall'inizio alla fine.

Laboratorio di 2 ore (anche 3 se la classe è lenta). Obiettivi: scegliere tra Flexbox e Grid, costruire un layout con grid-template-areas, rendere responsive una galleria, collaudare il sito con la modalità dispositivo, la tastiera e i validatori. Ogni studente lavora nella cartella cineforum con index.html e stile.css; a fine ora si salva su chiavetta o su Drive. Nessuna immagine da scaricare: le locandine sono riquadri colorati con il titolo, così non ci sono problemi di diritti.

Lo strumento giusto

Flexbox in una dimensione, Grid in due

Flexbox

Allinea elementi lungo una riga o una colonna. Le dimensioni partono dal contenuto.

menuintestazionepulsantidentro una card

Grid

Disegna righe e colonne insieme. Le dimensioni partono dal contenitore.

impaginazionegalleriatabella di cardmodulo
Regola pratica: se ti interessa che gli elementi siano allineati anche in verticale, tra una riga e l'altra, usa Grid.
Non è una legge: con entrambi si può fare quasi tutto, ma con fatica diversa. Nel nostro sito: header e menu con Flexbox, pagina e galleria con Grid. Domanda: e il contenuto di una singola locandina (titolo in alto, durata in basso)? Flexbox in colonna.

Mettiti alla prova

Sette locandine in colonne allineate, anche nell'ultima riga

  1. Flexbox con flex-wrap: wrap e flex: 1
  2. position: absolute per ogni locandina
  3. float: left come una volta
  4. Grid con tre colonne 1fr

Con flex-wrap e flex: 1 l'ultima riga ha una sola locandina che si allarga fino a riempire tutta la riga. Grid invece crea vere colonne: la settima locandina resta larga come le altre, nella prima colonna.

Il tranello è la A: funziona quasi, ma 7 elementi su 3 colonne lasciano 1 elemento nell'ultima riga, che con flex: 1 diventa largo tre volte. Si può mostrare dal vivo in CodePen. position: absolute toglie gli elementi dal flusso (lezione sul posizionamento) e non si adatta allo schermo.

Nella cartella cineforum crea index.html (con meta viewport e il link a stile.css) e scrivi questo corpo con 6 film veri che ti piacciono.

Controllo: su validator.w3.org, scheda Validate by File Upload, nessun errore. Senza CSS la pagina è una colonna leggibile, nell'ordine testa, film, orari, piede.
Gli elementi semantici (header, nav, main, article, aside, footer) sono quelli della lezione 1 dell'unità: aiutano screen reader e motori di ricerca. Il div.poster è un segnaposto colorato al posto della locandina vera. Chi vuole usare immagini vere deve usare locandine con licenza libera e un alt adeguato.

Il CSS base

Prima il telefono, senza media query

* { box-sizing: border-box; }
body { margin: 0; font-family: system-ui, sans-serif; }
.testa { display: flex; flex-wrap: wrap;
  justify-content: space-between; align-items: center;
  gap: 8px 24px; padding: 16px; }
.testa ul { display: flex; gap: 16px;
  list-style: none; margin: 0; padding: 0; }
.film, .orari, .piede { padding: 16px; }
.galleria { display: grid; gap: 16px; }
.poster { aspect-ratio: 2 / 3; display: grid;
  place-items: center; background: #11845f; color: #fff; }
  • flex-wrap: se lo spazio non basta, il menu va sotto il titolo da solo
  • space-between: titolo a sinistra, menu a destra
  • aspect-ratio: la locandina resta 2:3 a ogni larghezza
Far notare che la galleria è già una griglia, ma con una sola colonna implicita. Nessun width in pixel: è la ragione per cui a 360 px non c'è scorrimento orizzontale. box-sizing: border-box fa entrare padding e bordo nella larghezza (box model, Unità 4).

Al computer · 15 minuti

Passo 2: intestazione e locandine

  1. Crea stile.css e copia il CSS base della slide precedente.
  2. Apri index.html in Chrome o Edge, F12, Ctrl+Shift+M, larghezza 360.
  3. Allarga piano fino a 600 px e guarda quando il menu sale accanto al titolo.
  4. Nel pannello Elementi clicca il badge flex accanto a <header>: compare la sovrapposizione colorata.
  5. Rendi la locandina una colonna flex: titolo in alto, anno e durata in basso.
Controllo: a 360 px il menu sta sotto il titolo, più largo sale sulla stessa riga, a destra. In nessuna larghezza compare la barra di scorrimento orizzontale.
Il punto in cui il menu sale dipende dalla lunghezza del titolo e dei link: è un esempio di layout che si adatta al contenuto senza media query (ne parleremo nell'ultima lezione dell'unità). Il badge flex/grid nel pannello Elementi esiste in Chrome ed Edge recenti; in Firefox c'è un'icona simile.

L'impaginazione

Da 960 px: la pagina disegnata con i nomi

@media (min-width: 960px) {
  body {
    display: grid;
    grid-template-columns: 1fr 280px;
    grid-template-areas:
      "testa testa"
      "film  orari"
      "piede piede";
    column-gap: 24px;
  }
  .testa { grid-area: testa; }
  .film  { grid-area: film; }
  .orari { grid-area: orari; }
  .piede { grid-area: piede; }
}

Le stringhe di grid-template-areas sono una mappa della pagina: una stringa per riga, un nome per colonna.

Un nome ripetuto fa occupare più celle: "testa testa" prende tutta la larghezza.

La galleria, dentro .film, avrà le sue colonne: una griglia dentro un'altra.

Le aree devono essere rettangolari: una forma a L non è valida e la proprietà viene ignorata. I nomi sono sensibili alle maiuscole. Senza la media query il body resta in colonna, cioè il layout del telefono: mobile first.

Calcolo veloce

Body largo 1200 px: quanto è larga la colonna dei film?

Con il CSS della slide precedente: grid-template-columns: 1fr 280px e column-gap: 24px.

  1. 896 px
  2. 920 px
  3. 600 px
  4. 1176 px

1fr prende lo spazio che resta: 1200 − 280 − 24 = 896 px. Chi risponde 920 dimentica lo spazio tra le colonne; 600 è la metà, ma 1fr non vuol dire "metà".

Errore tipico: pensare che fr sia una percentuale. fr divide lo spazio libero dopo aver tolto le colonne fisse e i gap. Variante a voce: e se fossero 2fr 1fr senza colonne fisse? (1200 − 24) ÷ 3 = 392, quindi 784 e 392.

Al computer · 20 minuti

Passo 3: la griglia della pagina e della galleria

  1. Aggiungi in fondo a stile.css la media query da 960 px della slide precedente.
  2. Prima di quella, aggiungi @media (min-width: 600px) con .galleria { grid-template-columns: repeat(2, 1fr); }.
  3. Dentro la media query da 960 px aggiungi .galleria { grid-template-columns: repeat(3, 1fr); }.
  4. Prova a 360, 768 e 1280 px; nel pannello Elementi attiva il badge grid del body.
Controllo: 360 px: tutto in colonna, una locandina per riga. 768 px: due locandine per riga, orari sotto. 1280 px: tre locandine per riga e orari in una colonna di 280 px a destra.
L'ordine conta: la media query da 600 px va prima di quella da 960 (lezione precedente, quiz sull'ordine). Se a 1280 gli orari finiscono sotto, c'è un errore nei nomi delle aree o un punto e virgola mancante dopo l'ultima stringa. Chi finisce prima: aggiungere position: sticky e top: 0 alla testa (lezione sul posizionamento) e verificare che non copra i titoli.

Puzzle

Abbina la proprietà a quello che fa nel nostro sito

grid-template-areas
Disegna la mappa della pagina con i nomi
grid-area
Mette un elemento in una zona della mappa
justify-content: space-between
Spinge titolo e menu ai due lati
flex-wrap: wrap
Manda il menu a capo se non c'è posto
aspect-ratio: 2 / 3
Tiene la locandina sempre nelle stesse proporzioni
Gara a coppie, un minuto. Domanda extra: quale proprietà useresti per lasciare spazio tra le locandine? gap, che vale sia in Grid sia in Flexbox.

Trova l'errore

Tre siti che non si adattano: perché?

A 360 px compare la barra orizzontale.

.galleria { width: 1200px; }

Una larghezza fissa più grande dello schermo. Si toglie la width o si usa max-width.

Gli orari non vanno a destra.

.orari { grid-area: Orari; }

I nomi delle aree distinguono maiuscole e minuscole: Orari non è orari, e l'elemento viene messo in una cella libera.

Sul telefono si vede il layout da PC, minuscolo.

Il CSS è perfetto.

Manca il meta viewport: il telefono finge 980 px, quindi vale la media query da 960 px.

Far ipotizzare la causa a squadre prima di girare ogni carta. La terza è la più istruttiva: il codice CSS non c'entra, il problema è nell'HTML. Collega la lezione precedente con il laboratorio.

Al computer · 15 minuti

Passo 4: il collaudo

  1. Trascina la larghezza da 320 a 1920 px: nessun salto strano, nessuna scritta tagliata.
  2. Se compare la barra orizzontale, aggiungi per un attimo * { outline: 1px solid red; } e cerca il riquadro che esce.
  3. Chiudi la modalità dispositivo e scorri il sito solo con Tab: i link del menu si vedono quando hanno il focus?
  4. Valida il CSS su jigsaw.w3.org/css-validator, caricando stile.css.
Controllo: nessuno scorrimento orizzontale da 320 px in su, menu raggiungibile con Tab nell'ordine testa, film, orari, piede, validatore CSS con zero errori.
outline, a differenza di border, non occupa spazio: non cambia il layout mentre si cerca il colpevole. Ricordare di toglierlo alla fine. Se qualcuno ha spostato visivamente gli orari prima dei film con Grid, far notare che con Tab l'ordine resta quello dell'HTML: l'ordine visivo e quello del codice devono coincidere (criterio WCAG 1.3.2 e 2.4.3).

Oggi

Le griglie continuano a crescere

Oggi

subgrid

Dal 2023 tutti i browser principali supportano grid-template-rows: subgrid: le card di una galleria possono condividere le righe della griglia madre, così titoli e date restano allineati anche quando un titolo va a capo.

Oggi

Nei DevTools di Chrome c'è un assistente AI che spiega perché un elemento sta in un certo punto o esce dallo schermo. Serve un account e ci sono limiti di età: lo vediamo in demo. Le sovrapposizioni flex e grid, invece, sono per tutti.

subgrid: Firefox dal 2019, Safari 16 nel 2022, Chrome ed Edge 117 a settembre 2023. L'assistente AI dei DevTools di Chrome richiede l'accesso con un account Google e la maggiore età: il docente può mostrarlo sulla LIM con un elemento del sito di uno studente. Sottolineare che l'AI spiega, ma il collaudo con la modalità dispositivo resta compito nostro.
