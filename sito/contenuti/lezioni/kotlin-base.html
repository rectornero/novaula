Un po' di storia

Da un'isola russa al linguaggio di Android

2011

JetBrains, l'azienda di IntelliJ, presenta Kotlin. Il nome viene da un'isola vicino a San Pietroburgo, come Java è un'isola.

2016

Esce Kotlin 1.0, compatibile con Java: le due lingue convivono nello stesso progetto.

2017

Al Google I/O Kotlin diventa linguaggio ufficiale per Android.

2019

Google annuncia lo sviluppo Android "Kotlin-first": documentazione ed esempi prima in Kotlin.

Kotlin si compila in bytecode JVM: può usare tutte le librerie Java, e Java può chiamare il codice Kotlin.
Il progettista principale delle prime versioni è stato Andrey Breslav. Kotlin 2.0 (2024) ha introdotto il nuovo compilatore K2. Kotlin si compila anche in JavaScript, in codice nativo e in WebAssembly, ma per Android conta la strada JVM → DEX vista nella lezione 2. L'interoperabilità è stata la chiave del successo: le aziende hanno potuto aggiungere file Kotlin a progetti Java esistenti senza riscriverli.

Ciao, Kotlin

Lo stesso programma, due lingue

Java

public class Main {
  public static void main(String[] args) {
    final String nome = "5G";
    int anni = 18;
    System.out.println("Ciao " + nome
        + ", hai " + anni + " anni");
  }
}

Kotlin

fun main() {
    val nome = "5G"
    var anni = 18
    println("Ciao $nome, hai $anni anni")
}
  • Niente classe obbligatoria, niente punto e virgola.
  • I tipi si deducono: nome è String, anni è Int.
Template di stringa: $nome per una variabile, ${espressione} per un'espressione, per esempio ${anni + 1}. In Kotlin non ci sono tipi primitivi visibili: Int, Double, Boolean sono classi, ma il compilatore usa i primitivi della JVM quando può. Far notare che la funzione main può stare fuori da qualunque classe (funzione top-level).

val e var

Prima chiediti: questo valore cambierà?

val pi = 3.14      // Double, fisso
var punti = 0      // Int, riassegnabile
punti += 10
val classe: String = "5G"
pi = 3.0           // errore di compilazione
val msg = "Punti: ${punti * 2}"
val esito = if (punti >= 6) "ok"
            else "no"

Regola pratica

Usa val sempre, e passa a var solo quando serve davvero.

val è come final in Java. E if è un'espressione: restituisce un valore, al posto dell'operatore ternario.

msg vale "Punti: 20"; l'errore dice Val cannot be reassigned.

Kotlin non ha l'operatore ternario ? : di Java, perché if, when e try sono espressioni. Il compilatore e Android Studio segnalano le var che non vengono mai riassegnate. Domanda: perché preferire val? (Meno stati che cambiano, codice più facile da seguire e più sicuro con i thread.)

Quiz a trabocchetto

Questo codice compila?

val lista = mutableListOf(1, 2)
lista.add(3)
println(lista)
  1. No: lista è val
  2. Sì, stampa [1, 2, 3]
  3. Sì, ma add viene ignorato
  4. Compila, ma lancia un'eccezione

val blocca il riferimento, non l'oggetto: non puoi scrivere lista = altraLista, ma puoi modificare la lista mutabile. Come final in Java.

Classico malinteso: val = immutabile. In realtà val = riferimento non riassegnabile. Per una lista davvero non modificabile si usa listOf(1, 2), che restituisce una List senza metodo add: lì sì che lista.add(3) non compila. Far provare entrambe le versioni nel Playground.

Al computer · 15 minuti

La media dei voti nel Kotlin Playground

  1. Apri play.kotlinlang.org: non serve un account.
  2. Scrivi il programma a destra e premi Run.
  3. Aggiungi un voto 4 alla lista ed esegui di nuovo.
  4. Prova a riassegnare media: leggi l'errore.
  5. Copia il codice finale in media.kt.
fun main() {
    val voti = listOf(7, 8, 6, 9)
    var somma = 0
    for (v in voti) somma += v
    val media = somma.toDouble() / voti.size
    val esito = if (media >= 6) "promosso"
                else "da recuperare"
    println("Media: $media, $esito")
}
Controllo: Media: 7.5, promosso. Con il 4: Media: 6.8, promosso.
Errore atteso al punto 4: "Val cannot be reassigned". Se si toglie toDouble() la media diventa una divisione intera (7 invece di 7.5): stesso comportamento di Java. Versione idiomatica da mostrare alla fine: val media = voti.average(). Null safety

L'errore da un miliardo di dollari

In Java

Ogni riferimento può essere null. Lo scopri a runtime, con una NullPointerException.

In Kotlin

String non può mai essere null. Se serve, scrivi String? e il compilatore ti obbliga a gestirlo.

Traduzione nostra dall'originale inglese: "I call it my billion-dollar mistake. It was the invention of the null reference in 1965." Hoare introdusse il riferimento nullo nel linguaggio ALGOL W "perché era così facile da implementare". La cifra è la sua stima, retorica, dei danni causati in quarant'anni. Domanda: quante NullPointerException avete visto negli esercizi di Java di quest'anno?

Gli operatori del null

Quattro simboli da conoscere

var nome: String = "Ada"
nome = null                 // errore di compilazione
var nick: String? = null    // può essere null
println(nick?.length)        // null
println(nick?.length ?: 0)   // 0
if (nick != null) println(nick.length)   // smart cast
println(nick!!.length)       // NullPointerException

?

Dopo il tipo: può essere null.

?.

Chiamata sicura: se è null, dà null.

?:

Elvis: il valore di riserva.

!!

"Fidati di me": se è null, esplode.

Lo smart cast: dopo il controllo nick != null il compilatore tratta nick come String (non String?) dentro l'if, purché sia una variabile locale che non può cambiare nel frattempo. L'operatore Elvis si chiama così perché ?: ricorda il ciuffo di Elvis Presley visto di lato. Regola: un !! nel codice è un piccolo debito; nelle app Android si usa quasi solo quando si è certi, per esempio dopo un controllo.

Mettiti alla prova

Che cosa stampa questa riga?

println("42a".toIntOrNull() ?: 0)
  1. 42
  2. 0
  3. null
  4. NumberFormatException

toIntOrNull() non lancia eccezioni: se la stringa non è un intero valido restituisce null, e l'operatore Elvis lo sostituisce con 0.

Chi viene da Java pensa a Integer.parseInt, che lancia NumberFormatException (D): in Kotlin c'è anche toInt(), che si comporta così. La A è per chi pensa che la conversione "si fermi" alla prima lettera, come atoi in C. In Android, toIntOrNull() è il modo pulito per leggere un numero scritto dall'utente in un campo di testo.

Funzioni e when

Meno cerimonie, più chiarezza

fun area(base: Double, h: Double = 1.0): Double {
    return base * h
}
fun doppio(x: Int) = x * 2  // a espressione

fun giudizio(voto: Int) = when {
    voto >= 9 -> "ottimo"
    voto >= 6 -> "sufficiente"
    else -> "insufficiente"
}
area(4.0)                   // 4.0
area(h = 3.0, base = 2.0)   // 6.0
  • Il tipo sta dopo il nome: x: Int.
  • Argomenti con valore di default e con nome: niente overload.
  • when sostituisce switch ed è un'espressione.
  • Una funzione che non restituisce nulla restituisce Unit.
Unit corrisponde a void, ma è un vero tipo con un solo valore. when può anche confrontare con valori (when (x) { 1 -> ...; in 2..5 -> ...; else -> ... }) e con tipi (is String ->). Gli argomenti con nome rendono leggibili chiamate con molti parametri: in Android li vedrete spesso, per esempio nelle API di Compose.

Al computer · 20 minuti

Ripulire i dati scritti dagli utenti

  1. Nel Playground crea la lista input con listOf("8", "sette", "10", "", "6", null): è una List<String?>.
  2. Ottieni gli interi validi con input.mapNotNull { it?.toIntOrNull() }.
  3. Stampa quanti sono e la loro media con average().
  4. Scrivi fun giudizio(voto: Int) con when e stampala per ogni voto valido.
  5. Salva in pulizia.kt.
Controllo: Validi: 3, media: 8.0, poi 8 sufficiente, 10 ottimo, 6 sufficiente. Senza il ?. il codice non compila: perché?
Soluzione: val numeri = input.mapNotNull { it?.toIntOrNull() }; println("Validi: ${numeri.size}, media: ${numeri.average()}"); for (n in numeri) println("$n ${giudizio(n)}"). Senza ?. il compilatore segnala che it è String? e non si può chiamare toIntOrNull() su un valore che può essere null. La stringa vuota "" dà null come "sette". È esattamente il problema delle app: l'utente scrive di tutto in un campo.

Classi

Venti righe di Java, una di Kotlin

public class Studente {
  private final String nome;
  private final int voto;
  public Studente(String nome, int voto) {
    this.nome = nome; this.voto = voto;
  }
  public String getNome() { return nome; }
  public int getVoto() { return voto; }
  // + equals(), hashCode(), toString()...
}
data class Studente(
    val nome: String,
    val voto: Int
)
val s = Studente("Ada", 9)   // niente new
println(s)        // Studente(nome=Ada, voto=9)
val t = s.copy(voto = 10)

Il costruttore primario dichiara le proprietà. data genera equals, hashCode, toString e copy.

In Kotlin le classi sono final per default: per estenderle si scrive open class. Con == Kotlin chiama equals (confronto di contenuto); il confronto di riferimento è ===. Il record di Java 16 (usato nella lezione 1) è il parente più stretto della data class, ma è sempre immutabile e non ha copy. Le proprietà si leggono come campi (s.nome) ma dietro ci sono getter, compatibili con Java (getNome()).

Puzzle · Traduttore

Abbina il Java alla sua versione Kotlin

final String s = "a";
val s = "a"
String s = null;
var s: String? = null
s != null ? s.length() : 0
s?.length ?: 0
switch (x) { … }
when (x) { … }
record P(String n, int v)
data class P(val n: String, val v: Int)
x -> x * 2
{ it * 2 }
A coppie, 3 minuti. it è il nome implicito del parametro di una lambda con un solo argomento. Far notare che in Kotlin la lambda sta sempre tra graffe, anche quando è corta. Chiedere di leggere ad alta voce ogni riga Kotlin "in italiano": "s chiamata sicura length, altrimenti zero".

Lambda e collezioni

Il pezzo che userai di più in Android

val classe = listOf(Studente("Ada", 9),
    Studente("Linus", 6), Studente("Grace", 8))

val bravi = classe.filter { it.voto >= 8 }
                  .map { it.nome }
println(bravi)                 // [Ada, Grace]
println(classe.maxBy { it.voto }.nome)  // Ada

// in un'app Android, lezione 6:
bottone.setOnClickListener { mostraToast() }
  • Una lambda è un blocco di codice tra graffe, passato come valore.
  • Se è l'ultimo argomento, va fuori dalle parentesi.
  • È la stessa sintassi dei listener dei pulsanti.
Trailing lambda: f(x) { ... } equivale a f(x, { ... }); se la lambda è l'unico argomento le parentesi si omettono del tutto. setOnClickListener accetta un'interfaccia Java con un solo metodo (OnClickListener): Kotlin permette di passare una lambda al suo posto (SAM conversion). In Java sarebbe una classe anonima o una lambda Java. maxBy esiste da Kotlin 1.7 nella forma che lancia eccezione se la lista è vuota; maxByOrNull restituisce null.

Al computer · 20 minuti

Data class e lambda: il registro di classe

  1. Dichiara data class Studente(val nome: String, val voto: Int).
  2. Crea la lista: Ada 9, Linus 6, Grace 8, Alan 5.
  3. Stampa i nomi ordinati per voto decrescente (sortedByDescending, map).
  4. Stampa quanti sono sufficienti (count) e la media dei voti.
  5. Crea una copia di Grace con voto 10, stampala; poi salva in registro.kt.
Controllo: [Ada, Grace, Linus, Alan], poi 3 e 7.0, infine Studente(nome=Grace, voto=10). E Studente("Ada", 9) == Studente("Ada", 9) stampa true.
Soluzione: val c = listOf(Studente("Ada", 9), Studente("Linus", 6), Studente("Grace", 8), Studente("Alan", 5)); println(c.sortedByDescending { it.voto }.map { it.nome }); println(c.count { it.voto >= 6 }); println(c.map { it.voto }.average()); println(c[2].copy(voto = 10)). Media: 28 / 4 = 7.0. Il true finale dipende da data: con una class normale == confronterebbe i riferimenti (tramite equals ereditato) e stamperebbe false. Far togliere data per vederlo.

Puzzle

Dal file .kt al telefono: metti in ordine

  1. Scrivi MainActivity.kt in Android Studio
  2. Il compilatore Kotlin produce bytecode JVM (.class)
  3. D8 converte i .class in classes.dex
  4. Gradle impacchetta DEX e risorse in un APK firmato
  5. L'APK viene installato sul telefono
  6. ART esegue il DEX, compilandolo in parte in codice macchina
Ripasso della lezione 2 con il nuovo linguaggio. Kotlin e Java seguono la stessa strada fino al DEX: per questo possono convivere nella stessa app. Nella build di rilascio prima di D8 interviene di solito R8, che riduce e offusca il codice (minificazione).
