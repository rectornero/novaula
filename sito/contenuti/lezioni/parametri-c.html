UDA 7 · Funzioni e array in C e C++

Il passaggio
dei parametri

Una funzione riceve una copia dei tuoi dati o gli originali? Oggi scopriamo indirizzi e puntatori, senza paura.

Obiettivi: distinguere variabili locali e globali, capire il passaggio per valore (copia), conoscere indirizzi e puntatori (& e *), usare il passaggio per indirizzo in C (puntatori) e in C++ (riferimenti). Durata indicativa: 2-3 ore. I puntatori vanno introdotti con calma: l'obiettivo è capire lo scambio di due variabili e il perché della & in scanf, non l'aritmetica dei puntatori.

Per cominciare

Un amico deve sistemare la tua presentazione. Che cosa gli mandi?

  1. Una copia del file come allegato
  2. Il link al file originale su Drive
  3. Dipende da chi deve vedere le modifiche
Sondaggio senza risposta giusta, ma è la metafora di tutta la lezione. Allegato = copia: le sue modifiche non toccano il tuo file (passaggio per valore). Link condiviso = indirizzo dell'originale: le sue modifiche le vedi anche tu (passaggio per indirizzo). Tenere la metafora alla lavagna per tutta la lezione.

Condivisione di memoria

Variabili locali e globali

int punti = 0;      // globale

void bonus() {
    punti = punti + 10;
}
int main() {
    bonus();
    bonus();
    printf("Punti: %d\n", punti);
    return 0;
}

Locale

Dichiarata dentro una funzione: nasce e muore lì, le altre non la vedono.

Globale

Dichiarata fuori da tutte le funzioni: la condividono tutte. Comoda, ma chiunque può cambiarla.

Il programma stampa "Punti: 20" (verificato con gcc). La variabile globale è un primo modo di condividere memoria tra funzioni. Perché è rischiosa? In un programma di migliaia di righe non sai più chi l'ha modificata. Per questo si preferisce passare i dati come parametri: è chiaro chi riceve che cosa.

Quiz a trabocchetto

Che cosa stampa il main?

int x = 5;           // globale

void cambia() {
    int x = 99;      // locale
}
int main() {
    cambia();
    printf("%d", x);
    return 0;
}
  1. 99
  2. 0
  3. Errore di compilazione
  4. 5

Dentro cambia, int x crea una nuova variabile locale che "copre" quella globale e sparisce alla fine della funzione. La x globale resta 5.

Verificato con gcc: stampa 5 (il compilatore avvisa solo che la x locale non viene usata). Chi risponde 99 non ha notato la parola int davanti a x: senza int, cambia modificherebbe la globale. La C è un dubbio legittimo: nello stesso blocco due variabili con lo stesso nome sono un errore, in blocchi diversi no.

Il passaggio per valore

La funzione riceve una copia

void raddoppia(int n) {
    n = n * 2;
    printf("dentro: %d\n", n);
}
int main() {
    int voto = 4;
    raddoppia(voto);
    printf("fuori: %d\n", voto);
    return 0;
}
4voto 8n

Stampa dentro: 8 e poi fuori: 4.

Il valore di voto viene copiato in n. La funzione lavora sulla copia: l'originale non cambia.
Verificato con gcc. È come l'allegato del sondaggio iniziale. In C il passaggio per valore è il modo normale: tutti i parametri visti nella lezione precedente erano passati per valore. Se vogliamo che il main riceva il nuovo valore, la via più semplice è restituirlo con return: voto = raddoppia(voto).

Quiz

Lo scambio funziona?

void scambia(int a, int b) {
    int t = a;
    a = b;
    b = t;
}
int main() {
    int x = 1, y = 2;
    scambia(x, y);
    printf("%d %d", x, y);
    return 0;
}
  1. 2 1
  2. 1 2
  3. 2 2
  4. 1 1

scambia scambia le sue copie a e b, non x e y. Quando la funzione finisce le copie spariscono: il main stampa ancora 1 2.

Verificato con gcc: stampa "1 2". È la misconcezione più diffusa sulle funzioni: il codice dello scambio con la variabile di appoggio t (visto nella UDA 6) è giusto, ma lavora sulle copie. Lasciare la domanda aperta: "come facciamo a scambiare davvero x e y?" La risposta arriva tra poco con i puntatori.

Al computer · 15 minuti

Caccia alla copia

  1. Su OnlineGDB (linguaggio C) scrivi il programma raddoppia della slide 5 ed eseguilo.
  2. Aggiungi in main e in raddoppia una printf che stampa il valore prima e dopo il calcolo.
  3. Ora trasformala in funzione: int raddoppia(int n) con return n * 2;
  4. Nel main scrivi voto = raddoppia(voto); e stampa di nuovo.
  5. Salva come valore.c.
Controllo: con la prima versione il main stampa fuori: 4; con la seconda stampa 8. Il valore torna al main solo grazie al return.
Soluzione della seconda versione: int raddoppia(int n) { return n * 2; } int main() { int voto = 4; voto = raddoppia(voto); printf("fuori: %d\n", voto); return 0; } Stampa "fuori: 8". Far osservare che return restituisce un solo valore: per "restituire" due valori (come nello scambio) serve un'altra strada.

Il tipo puntatore

Ogni variabile abita a un indirizzo

La memoria è come una lunga via: ogni cella ha un numero civico, l'indirizzo, e dentro c'è un valore.

41000 71004 01008 11012 21016

&a

"Indirizzo di a": dove abita la variabile, per esempio 1004.

int *p

Un puntatore: una variabile che contiene un indirizzo.

Gli indirizzi 1000, 1004... sono inventati per semplicità; un int occupa di solito 4 byte, per questo crescono di 4. Gli indirizzi veri sono numeri molto grandi scritti in esadecimale, per esempio 0x7ffd5e8c (si possono vedere con printf("%p", &a)): collegamento con la lezione sull'esadecimale. Metafora: il puntatore è un bigliettino con scritto un indirizzo di casa.

Il tipo puntatore

Due simboli da ricordare: & e *

int a = 7;
int *p = &a;   // p punta ad a

printf("%d", *p); // stampa 7

*p = 3;          // cambia a!
printf("%d", a);  // stampa 3

Che cosa fa &?

&a dà l'indirizzo della variabile a.

Che cosa fa * davanti a p?

*p è il valore che si trova all'indirizzo contenuto in p.

Perché a diventa 3?

Perché *p e a sono la stessa cella di memoria.

Leggere ad alta voce: "int *p" = "p è un puntatore a int"; "&a" = "indirizzo di a"; "*p" = "il contenuto puntato da p". Attenzione alla doppia vita dell'asterisco: nella dichiarazione (int *p) dice "è un puntatore", nelle istruzioni (*p = 3) vuol dire "vai all'indirizzo e usa il contenuto". Far girare le carte una alla volta chiedendo prima la risposta.

Puzzle

Abbina il codice al suo significato

int *p;
p è un puntatore a un intero
&a
L'indirizzo della variabile a
*p
Il valore che si trova all'indirizzo contenuto in p
p = &a;
Da ora p punta alla variabile a
p = NULL;
p non punta a niente
Abbinamenti giusti come scritti. NULL è un valore speciale: un puntatore che non punta a nessuna cella. Usare *p quando p vale NULL fa andare in crash il programma: è l'errore di cui parla Tony Hoare nella prossima slide.

Menti che ci hanno preceduto

L'errore da un miliardo di dollari

Oggi

Gli errori con puntatori e memoria sono ancora tra i più pericolosi: Microsoft ha raccontato che circa il 70% delle falle di sicurezza corrette ogni anno nei suoi prodotti nasce da problemi di memoria. Per questo crescono linguaggi "sicuri per la memoria" come Rust.

Traduzione nostra dall'inglese: "I call it my billion-dollar mistake. It was the invention of the null reference in 1965." Tony Hoare, conferenza QCon London 2009. Il dato del 70% è di Matt Miller (Microsoft Security Response Center), presentazione al BlueHat IL 2019; anche il team di Chromium (Google) ha riportato una percentuale simile per i bug gravi. Nel 2024 un rapporto della Casa Bianca (ONCD) ha invitato a preferire linguaggi sicuri per la memoria. Messaggio: i puntatori sono potentissimi, per questo vanno usati con attenzione.

Il passaggio per indirizzo in C

Ora lo scambio funziona

void scambia(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
int main() {
    int x = 1, y = 2;
    scambia(&x, &y);
    printf("%d %d", x, y);  // 2 1
    return 0;
}

La funzione riceve gli indirizzi di x e y, quindi lavora sugli originali.

Ecco perché scrivi scanf("%d", &x): scanf deve sapere dove mettere il numero letto!
Verificato con gcc: stampa "2 1". È come il link condiviso del sondaggio. Far notare le tre differenze con la versione sbagliata: int *a nei parametri, *a nel corpo, &x nella chiamata. Il collegamento con scanf di solito produce un "aaah" in classe: la & che usavano dalla UDA 6 ora ha un senso.

Puzzle

Metti in ordine: che cosa succede con scambia(&x, &y)?

  1. Il main passa a scambia gli indirizzi di x e y
  2. a riceve l'indirizzo di x, b quello di y
  3. t = *a copia in t il valore di x, cioè 1
  4. *a = *b scrive in x il valore di y, cioè 2
  5. *b = t scrive in y il vecchio valore di x
  6. Tornato nel main, x vale 2 e y vale 1
Ordine giusto come scritto. Per chi è in difficoltà: disegnare alla lavagna le celle x e y con le frecce che partono da a e b. Variante a squadre: due studenti fanno x e y con un foglio in mano, un terzo fa la funzione e può solo "andare all'indirizzo" e cambiare il foglio.

Al computer · 20 minuti

Metti in ordine due numeri

  1. In C scrivi la funzione void scambia(int *a, int *b) della slide 12.
  2. Scrivi void ordina2(int *a, int *b): se *a > *b chiama scambia(a, b).
  3. Nel main leggi due numeri con scanf, chiama ordina2(&x, &y) e stampali.
  4. Prova anche con due numeri uguali e con due negativi.
  5. Salva come indirizzo.c.
Controllo: con 9 4 stampa 4 9; con 3 8 stampa 3 8; con -1 -5 stampa -5 -1.
Soluzione: void ordina2(int *a, int *b) { if (*a > *b) scambia(a, b); } int main() { int x, y; scanf("%d %d", &x, &y); ordina2(&x, &y); printf("%d %d\n", x, y); return 0; } Verificato con gcc. Domanda chiave: perché dentro ordina2 si scrive scambia(a, b) e non scambia(&a, &b)? Perché a e b sono già indirizzi. Questo è il primo mattone degli algoritmi di ordinamento che vedremo a fine UDA.

Il passaggio per indirizzo in C++

In C++ basta una & nel parametro

void scambia(int &a, int &b) {
    int t = a;
    a = b;
    b = t;
}
// nel main:
scambia(x, y);   // niente & qui

Il parametro int &a è un riferimento: un altro nome per la stessa variabile. Niente asterischi.

Oggi

Quando condividi il link di un Google Doc, tutti lavorano sullo stesso file: è un passaggio per indirizzo. Quando mandi un allegato, ognuno modifica la sua copia: è un passaggio per valore.

Verificato con g++: con x = 1 e y = 2 dopo scambia(x, y) stampa "2 1". Il riferimento del C++ fa la stessa cosa del puntatore, ma il compilatore si occupa degli indirizzi al posto nostro. Attenzione: la & nel parametro (int &a) significa "riferimento", la & davanti a una variabile in un'istruzione (&x) significa "indirizzo di".

Al computer · 20 minuti

Il salvadanaio, in C++

  1. Su OnlineGDB scegli C++.
  2. Scrivi void deposita(float &saldo, float importo) che aggiunge l'importo al saldo.
  3. Scrivi void preleva(float &saldo, float importo): toglie l'importo solo se basta il saldo, altrimenti stampa Saldo insufficiente.
  4. Nel main: saldo 0, deposita 20, preleva 5, preleva 50, poi stampa il saldo.
  5. Salva come salvadanaio.cpp.
Controllo: compare una volta Saldo insufficiente e alla fine Saldo: 15. Prova a togliere la & da deposita: che cosa succede al saldo?
Soluzione: void deposita(float &saldo, float importo) { saldo = saldo + importo; } void preleva(float &saldo, float importo) { if (importo <= saldo) saldo = saldo - importo; else cout << "Saldo insufficiente" << endl; } Verificato con g++. Senza la & in deposita il saldo resta 0 (passaggio per valore) e il prelievo di 5 diventa "Saldo insufficiente": ottimo per far vedere la differenza.

Sfida finale

Apri il lucchetto con i parametri

  • 1ª cifra: dopo lo scambio per valore della slide 6, quanto vale x
  • 2ª cifra: int a = 7; int *p = &a; *p = *p + 1; quanto vale a
  • 3ª cifra: quante & scrivi nella chiamata scambia(&x, &y)

Lucchetto aperto! Lo scambio per valore non cambia x (1), *p modifica a (8), due indirizzi (2), la copia non tocca voto (4).

Biglietto d'uscita

Completa prima di uscire

Nel passaggio per valore la funzione riceve una del dato.

L'operatore & restituisce l' di una variabile.

Una variabile che contiene un indirizzo si chiama .

Una variabile dichiarata fuori da tutte le funzioni si chiama .

In C++ il parametro int &a si chiama .
