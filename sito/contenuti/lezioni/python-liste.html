Parentesi quadre, elementi separati da virgole. A differenza dei vettori del C, una lista Python non ha una dimensione fissa: può crescere e accorciarsi.
Collegamento con la UDA 7: il vettore del C ha dimensione e tipo fissi (int voti[30]). La lista Python è più flessibile: può contenere anche tipi diversi, per esempio ["Ada", 14, 1.62], anche se di solito si tengono dati dello stesso tipo. Gli array "veri" a dimensione fissa in Python esistono nelle librerie, come NumPy, molto usata nell'AI.

Scorrere una lista

Due modi di fare il giro con il for

Per elemento: comodo quando ti serve solo il valore.

somma = 0
for v in voti:
    somma += v
print(somma / len(voti))

Per indice: serve quando ti interessa anche la posizione.

for i in range(len(voti)):
    print(i, voti[i])
Scorciatoia: sum(voti) / len(voti) dà la stessa media. Ma saper scrivere il ciclo serve quando la funzione pronta non c'è.
Con voti = [7, 5, 8, 6, 9] la media è 7.0. range(len(voti)) produce 0, 1, 2, 3, 4: proprio gli indici validi. Il for per elemento è più "pythonico"; quello per indice servirà per le liste parallele. Per i curiosi: esiste anche enumerate(voti), che dà insieme indice e valore.

Quiz a trabocchetto

Che cosa stampa l'ultima riga?

a = [1, 2, 3]
b = a
b.append(4)
print(a)
  1. [1, 2, 3]
  2. [1, 2, 3, 4]
  3. [4]
  4. Un errore

b = a non copia la lista: le dà un secondo nome. a e b sono la stessa lista, quindi l'append si vede da tutti e due. Per una copia vera: b = a.copy().

Il trabocchetto più famoso delle liste: quasi tutti rispondono A, perché con i numeri (x = 5; y = x; y = y + 1) la x non cambia. Analogia: una playlist condivisa con un amico. Se lui aggiunge una canzone, la vedi anche tu: è la stessa playlist, non una copia. Far verificare in IDLE, poi provare con b = a.copy().

Le liste parallele

Stesso indice, stessa persona

Indicenomivoti
0Ada8
1Alan7
2Grace9
nomi = ["Ada", "Alan", "Grace"]
voti = [8, 7, 9]
for i in range(len(nomi)):
    print(nomi[i], voti[i])
Due (o più) liste della stessa lunghezza: l'elemento i di una corrisponde all'elemento i dell'altra. Se ne ordini o modifichi una sola, l'abbinamento si rompe.
È lo stesso schema dei vettori paralleli del C. Rischio tipico: aggiungere un nome con append e dimenticare il voto, così le liste hanno lunghezze diverse e gli indici non corrispondono più. Più avanti negli studi si useranno strutture che tengono insieme i dati (dizionari, oggetti), ma l'idea delle liste parallele resta utile, per esempio nei fogli di calcolo: una colonna è una lista.

Oggi

Per un modello linguistico una frase è una lista di numeri: ogni token (un pezzo di parola) ha il suo numero nel vocabolario del modello. Una foto, invece, è una lista di righe di pixel: una lista di liste.

Il titolo originale è "Algorithms + Data Structures = Programs" (Prentice-Hall, 1976). Wirth ha ricevuto il premio Turing nel 1984. La lista è la prima struttura dati che incontriamo in Python. Sui token: per esempio una frase di 10 parole può diventare una lista di una quindicina di numeri, a seconda di come il modello spezza le parole; il modello lavora solo su quei numeri e alla fine li ritrasforma in testo.

Liste e intelligenza artificiale

Canzoni simili, liste di numeri simili

# energia, ballabilità, malinconia
a = [9, 8, 1]
b = [8, 9, 2]
c = [2, 1, 9]
def distanza(x, y):
    d = 0
    for i in range(len(x)):
        d += abs(x[i] - y[i])
    return d
print(distanza(a, b))  # 3
print(distanza(a, c))  # 22

Oggi

Molti sistemi che consigliano canzoni o video rappresentano ogni brano come una lista di numeri, calcolata da un modello di AI. Brani con liste vicine sono "simili": se ti piace a, ti propongono b, non c.

Attenzione: i numeri dell'esempio sono inventati e sono solo 3. Nei sistemi veri sono centinaia per ogni brano, e il loro significato non lo sceglie una persona.

Queste liste di numeri si chiamano embedding. L'esempio è volutamente semplice: i sistemi reali non usano 3 caratteristiche scelte a mano ma vettori lunghi imparati dai dati, e misure di distanza un po' diverse. La funzione distanza riusa tutto quello che abbiamo visto: funzione, for per indice, liste parallele (x[i] e y[i] sono la stessa caratteristica), accumulatore e abs.
