Perché Python

Lo stesso programma, due linguaggi

In C (UDA 6)

#include <stdio.h>
int main() {
    printf("Ciao, mondo!\n");
    return 0;
}

In Python

print("Ciao, mondo!")
  • niente punto e virgola, niente graffe
  • niente main obbligatorio
  • è un linguaggio interpretato: l'interprete legge ed esegue le istruzioni una dopo l'altra
Il C va compilato: il compilatore traduce tutto il programma in linguaggio macchina e poi lo si esegue. Python è interpretato: si scrive e si esegue subito, anche una riga alla volta nella shell. (Per precisione: l'interprete CPython traduce prima il codice in un formato intermedio, il bytecode, e poi lo esegue; ai ragazzi basta l'idea di "esecuzione immediata".) Chiedere: quale dei due è più facile da leggere? Il prezzo da pagare è la velocità: Python è in genere più lento del C.

Al computer · 15 minuti

Python come calcolatrice

  1. Apri IDLE (o un interprete online come OnlineGDB, lingua Python 3). Si apre la shell con il prompt >>>.
  2. Scrivi e premi Invio: print("Ciao, mondo!"), poi 2 + 3 * 4, 7 / 2, 7 // 2, 7 % 2, 2 ** 10.
  3. Ora File, New File: scrivi un programma di 3 print che si presenta (nome, classe, una passione).
  4. Salva come presentazione.py e premi F5 per eseguirlo.
Controllo: nella shell devi ottenere 14, 3.5, 3, 1 e 1024. Il programma stampa 3 righe. Se compare un errore in rosso, controlla virgolette e parentesi.
Risultati: 2 + 3 * 4 = 14 (la moltiplicazione ha la precedenza), 7 / 2 = 3.5 (divisione con la virgola, Python usa il punto), 7 // 2 = 3 (divisione intera), 7 % 2 = 1 (resto), 2 ** 10 = 1024 (potenza: un kibibyte, collegamento alla lezione sui numeri binari). Errore tipico: Print con la P maiuscola, che dà NameError. Python distingue maiuscole e minuscole. In OnlineGDB si clicca Run invece di F5 e il file si scarica con l'icona Download.

Le variabili

Una variabile è un nome attaccato a un valore

nome = "Ada"      # stringa (str)
eta = 14           # intero (int)
altezza = 1.62     # con la virgola (float)
eta = eta + 1      # ora vale 15
print(nome, "ha", eta, "anni")

Regole per i nomi

  • lettere, cifre e _
  • non iniziano con una cifra
  • Eta e eta sono diverse
  • niente parole riservate come if
Differenza con il C: in Python non si dichiara il tipo. Il tipo lo decide il valore, e = vuol dire "assegna", non "è uguale".
Output: Ada ha 15 anni (print separa gli argomenti con uno spazio). In C si scriveva int eta = 14; qui basta eta = 14. La funzione type() mostra il tipo: type(1.62) restituisce float. Leggere eta = eta + 1 da destra a sinistra: "calcola eta + 1 e metti il risultato in eta". In matematica sarebbe un'equazione impossibile: ottimo spunto per chiarire che = è un'assegnazione.

Quiz

Che cosa stampa questo programma?

x = 5
x = x + 2
y = x * 2
x = 1
print(y)
  1. 2
  2. 12
  3. 14
  4. 10

y vale 14: è stato calcolato quando x valeva 7. Cambiare x dopo non modifica y.

Il tranello è la A: molti pensano che y sia "collegato" a x come una formula di Calc, e quindi che diventi 1 * 2 = 2. In un programma l'assegnazione si fa una volta sola, nel momento in cui la riga viene eseguita. La D (10) è di chi dimentica la seconda riga, la B di chi somma male. Espressioni

Gli operatori aritmetici

OperatoreSignificatoEsempioRisultato
+ - *somma, differenza, prodotto3 * 4 - 210
/divisione (sempre con la virgola)6 / 32.0
//divisione intera17 // 53

Precedenze come in matematica: prima **, poi * / // %, poi + -. Nel dubbio, usa le parentesi tonde.
Differenza importante con il C: in C 7 / 2 tra interi fa 3, in Python fa 3.5. Per la divisione intera Python usa //. Il resto % servirà per capire se un numero è pari (n % 2 == 0) nella lezione sulla selezione. Esempio di precedenza: 2 + 3 ** 2 = 11, (2 + 3) ** 2 = 25.

Scambio di due variabili

Come si scambia il contenuto di due bicchieri?

Se scrivi a = b e poi b = a, il valore di a è perso. Serve un terzo bicchiere: temp.

Rimetti in ordine le righe: alla fine il programma stampa 8 3.

In Python c'è anche la scorciatoia a, b = b, a
  1. a, b = 3, 8
  2. temp = a
  3. a = b
  4. b = temp
  5. print(a, b)
Lo stesso problema fatto in C nella UDA 6. Ordine corretto: a, b = 3, 8; temp = a; a = b; b = temp; print(a, b). Far provare anche la versione sbagliata a = b; b = a: stampa 8 8. La scorciatoia a, b = b, a è tipica di Python: a destra si costruisce prima la coppia (8, 3), poi la si assegna. In C non esiste.

L'input

input() chiede, l'utente risponde

nome = input("Come ti chiami? ")
anno = int(input("Anno di nascita? "))
print("Ciao", nome)
print("Nel 2030 avrai", 2030 - anno, "anni")

Attenzione

input() restituisce sempre una stringa. Per fare i conti la trasformi con int() o float().

Oggi

Anche il messaggio che scrivi a un chatbot arriva al programma come stringa. Prima di elaborarlo, il modello lo spezza in token (pezzi di parola) e trasforma ogni token in un numero: anche per l'AI il testo diventa conti.

Con anno 2012 il programma stampa "Nel 2030 avrai 18 anni". Se l'utente scrive "ciao" invece di un numero, int() dà ValueError: lo gestiremo con la selezione e i cicli. I token: un modello linguistico non legge lettera per lettera né parola per parola, ma a pezzi; ogni pezzo ha un numero identificativo nel suo vocabolario. Ci torneremo nella lezione sulle liste.

Quiz a trabocchetto

L'utente scrive 7 e poi 3. Che cosa compare?

a = input("Primo numero: ")
b = input("Secondo numero: ")
print(a + b)
  1. 10
  2. 73
  3. Un errore
  4. a + b

a e b sono stringhe, e + tra stringhe le attacca: "7" + "3" = "73". Per avere 10 serve int(input(…)).

È l'errore più frequente di chi inizia con Python. La C (errore) è plausibile: chi viene dal C si aspetta un problema di tipi, ma il + tra due stringhe è lecito (concatenazione). Errore vero si avrebbe con "7" + 3 (TypeError: stringa più intero). La D è di chi confonde la variabile con il testo tra virgolette.

Al computer · 15 minuti

Il convertitore di paghette

  1. In IDLE apri File, New File.
  2. Chiedi il nome e la paghetta settimanale in euro (usa float(input(…))).
  3. Calcola quanto mette da parte in un anno (52 settimane) e quanti mesi servono per una cuffia da 60 euro, supponendo 4 settimane al mese.
  4. Stampa i risultati con una frase. Salva come paghetta.py e premi F5.
Controllo: con 5 euro a settimana ottieni 260.0 euro in un anno e 3.0 mesi per la cuffia. Se ottieni un errore TypeError, hai dimenticato float().
Soluzione: nome = input("Come ti chiami? ") paghetta = float(input("Paghetta settimanale? ")) anno = paghetta * 52 mesi = 60 / (paghetta * 4) print(nome, "in un anno metti da parte", anno, "euro") print("Per la cuffia servono", mesi, "mesi") Con 5 euro: 260.0 e 3.0. Con 7 euro i mesi sono 2.142857142857143: buona occasione per anticipare round(mesi, 1), che dà 2.1. Chi finisce prima può aggiungere quanto risparmia in 3 anni.

Contatore e accumulatore

Due variabili che lavorano sempre

Contatore

Che cosa fa?

Conta quante volte succede qualcosa.

conta = conta + 1

Parte da 0 e cresce sempre di 1. Esempio: quanti voti ho inserito.

Accumulatore

Che cosa fa?

Somma valori diversi uno dopo l'altro.

somma = somma + voto

Parte da 0 e cresce del valore letto. Esempio: la somma dei voti.

Forma breve: conta += 1 e somma += voto. Prima di usarli, ricorda di metterli a 0.
Prima di girare le carte, chiedere alla classe di indovinare la differenza. Collegare ai flow chart della UDA 5, dove contatore e accumulatore comparivano nei cicli. Se si dimentica di inizializzare (conta = 0), Python dà NameError: la variabile non esiste ancora. Nella lezione sul while li useremo dentro un ciclo.

Al computer · 15 minuti

La media di tre voti

  1. Crea un nuovo file e scrivi somma = 0 e conta = 0.
  2. Tre volte: leggi un voto con float(input(…)), poi somma += voto e conta += 1.
  3. Calcola media = somma / conta e stampa somma, numero di voti e media.
  4. Salva come media3.py ed esegui con F5.
Controllo: con i voti 7, 8 e 6 il programma stampa somma 21.0, voti 3 e media 7.0.
Soluzione: somma = 0 conta = 0 voto = float(input("Voto: ")) somma += voto conta += 1 (ripetuto tre volte) media = somma / conta print("Somma", somma, "voti", conta, "media", media) Far notare che abbiamo copiato tre volte le stesse righe: con 30 voti sarebbe scomodo. Il ciclo while e il ciclo for risolveranno il problema. Chi finisce prima: con 7.5, 8 e 6 la media è 7.166666666666667, usare round(media, 2).
