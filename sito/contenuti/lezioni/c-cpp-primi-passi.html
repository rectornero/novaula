I linguaggi C e C++

Due linguaggi, una famiglia

1972

Il C

Nasce ai Bell Labs (USA) per opera di Dennis Ritchie, per scrivere il sistema operativo Unix. È veloce, compatto e vicino all'hardware.

1983

Il C++

Bjarne Stroustrup, sempre ai Bell Labs, aggiunge al C le classi e molto altro. Il nome C++ significa "il C, un passo avanti".

Sono linguaggi imperativi: il programma è una sequenza di ordini che il computer esegue uno dopo l'altro. Quasi tutto ciò che scrivi in C funziona anche in C++.
Stroustrup iniziò nel 1979 con "C with Classes"; il nome C++ è del 1983 e la prima versione commerciale del 1985. L'operatore ++ in C significa "aumenta di uno": da qui la battuta del nome. Chiedere: quali altri linguaggi conoscete? Molti (Java, C#, JavaScript, PHP) hanno preso dal C la sintassi con graffe e punto e virgola.

Sistemi operativi

Il cuore di Linux e di Android è scritto in C.

Videogiochi

Motori grafici come Unreal Engine sono in C++.

Microcontrollori

La scheda Arduino si programma in C++.

Oggi

Quando un'AI riconosce una foto, i calcoli pesanti li fa codice C e C++: le librerie usate per addestrare le reti neurali, come PyTorch, hanno il motore scritto in C++. E l'interprete Python più usato è scritto in C.

Fonti verificabili: il kernel Linux è scritto quasi tutto in C (da poco anche qualche parte in Rust); Unreal Engine è in C++; il linguaggio di Arduino è C++ con alcune librerie; il nucleo di PyTorch (libtorch) è in C++; CPython, l'interprete Python ufficiale, è in C. Mettiti alla prova

Che cosa fa il compilatore?

  1. Esegue il programma riga per riga mentre lo legge
  2. Traduce tutto il sorgente in linguaggio macchina e segnala gli errori di sintassi
  3. Trova tutti gli errori del programma, anche quelli di logica
  4. Salva il file .c sul disco fisso

Il compilatore traduce il sorgente tutto insieme, prima dell'esecuzione. Se un programma calcola la media sbagliata ma è scritto con la sintassi giusta, il compilatore non se ne accorge: gli errori di logica li trovi solo provando il programma.

Tranelli: A descrive un interprete (come Python in modalità interattiva), C è il malinteso più diffuso: "se compila, è giusto". Far ripetere la frase: compila non vuol dire funziona.

Il primo programma

Ciao, mondo! In C e in C++

C · ciao.c

#include <stdio.h>

int main() {
    printf("Ciao, mondo!\n");
    return 0;
}

C++ · ciao.cpp

#include <iostream>
using namespace std;

int main() {
    cout << "Ciao, mondo!" << endl;
    return 0;
}

Stesso risultato, due strade: in C si stampa con printf, in C++ con cout. \n ed endl vanno a capo.

Leggere il codice ad alta voce, riga per riga. Far notare le parti uguali (main, graffe, return 0, punto e virgola) e quelle diverse (libreria, istruzione di stampa). Le stringhe vanno tra virgolette doppie. In C++ "using namespace std;" evita di scrivere std::cout ogni volta.

Al computer · 15 minuti

Il tuo primo programma (e il tuo primo errore)

  1. Apri onlinegdb.com (non serve un account) e in alto a destra scegli il linguaggio C. Oppure apri Code::Blocks o Dev-C++.
  2. Scrivi il programma Ciao, mondo, ma fai stampare Ciao, sono seguito dal tuo nome. Premi Run.
  3. Ora cancella il ; dopo la printf e riesegui: leggi l'errore.
  4. Rimetti il ;, passa a C++ e riscrivilo con cout.
  5. Salva il file come ciao-cognome.cpp.
Controllo: nella console compare Ciao, sono Giulia. Senza il punto e virgola il compilatore dice expected ';' before 'return': l'errore è segnalato sulla riga dopo!
Soluzione C: printf("Ciao, sono Giulia\n"); Soluzione C++: cout << "Ciao, sono Giulia" << endl; Messaggio di gcc verificato: "error: expected ';' before 'return'". Far notare che il compilatore indica il punto in cui si accorge dell'errore, spesso la riga successiva. Salvataggio: su OnlineGDB il pulsante Download scarica il file (da rinominare); in Code::Blocks e Dev-C++ File, Salva con nome. Evitare le lettere accentate nelle stringhe: la console di Windows può mostrarle male.

Dati e variabili

Una variabile è una scatola con un nome

TipoContieneEsempio
intnumeri interiint eta = 14;
floatnumeri con la virgolafloat h = 1.65;
doubledecimali più precisidouble pi = 3.14159;
charun solo caratterechar voto = 'A';

Regole per i nomi

  • lettere, cifre e _
  • non iniziano con una cifra
  • niente spazi né accenti
  • Voto e voto sono diversi
Prima si dichiara la variabile (tipo e nome), poi la si usa. Nei decimali si usa il punto, non la virgola: 1.65.
La variabile occupa celle della RAM (collegamento con la lezione sui componenti del computer). Un int occupa di solito 4 byte, un char 1 byte. Le parole riservate (int, return, if, for...) non si possono usare come nomi. I caratteri si scrivono tra apici singoli, le stringhe tra virgolette doppie.

Quiz a trabocchetto

Quale nome di variabile è valido in C?

  1. 2anni
  2. voto finale
  3. int
  4. media_2

media_2 usa solo lettere, cifre e trattino basso e non inizia con una cifra. 2anni inizia con una cifra, voto finale contiene uno spazio, int è una parola riservata del linguaggio.

Il tranello è C: "int" è fatto solo di lettere, ma è una parola riservata. Molti scelgono anche B perché in italiano è naturale. Convenzione utile: usare nomi parlanti in minuscolo con il trattino basso (media_voti) oppure con la maiuscola interna (mediaVoti).

L'assegnazione

Quanto vale la variabile alla fine?

In C il segno = non vuol dire "è uguale": vuol dire "metti nella scatola". Prima si calcola a destra, poi si scrive a sinistra.

int a = 5;
a = a * 2;

Quanto vale a?

a vale 10.

Prende il 5, lo moltiplica per 2 e lo rimette in a.

int b = 7;
b = b - 10;

Quanto vale b?

b vale -3.

Un int può essere anche negativo.

int c = 3;
c = c + c;
c = c + 1;

Quanto vale c?

c vale 7.

Prima 3 + 3 = 6, poi 6 + 1 = 7.

In matematica a = a * 2 sarebbe vera solo per a = 0; in C è un'istruzione che cambia il valore. Far scrivere su un foglio la "tabella di traccia" con il valore dopo ogni riga prima di girare le carte.

Al computer · 20 minuti

Area e perimetro di un rettangolo

  1. In C dichiara int base = 7; e int altezza = 4;
  2. Dichiara area e perimetro e calcolali con * e +.
  3. Stampali con printf("Area: %d\n", area);
  4. Cambia i valori in 12 e 5 e riesegui.
  5. Salva come rettangolo-cognome.c.
Controllo: con 7 e 4 esce Area: 28 e Perimetro: 22. Con 12 e 5: area 60, perimetro 34.

%d è il posto in cui printf scrive un intero: lo vedremo bene nella prossima lezione.

Soluzione: int base = 7; int altezza = 4; int area, perimetro; area = base * altezza; perimetro = 2 * (base + altezza); printf("Area: %d\n", area); printf("Perimetro: %d\n", perimetro); Errore tipico: perimetro = 2 * base + altezza (dà 18): ricordare le precedenze, servono le parentesi. Chi finisce prima scrive la versione C++ con cout.

Scambiare due variabili

Come scambi il succo con l'acqua?

Partenza: a = 3 e b = 8. Obiettivo: a = 8 e b = 3.

Così non funziona

a = b;  // a = 8, b = 8
b = a;  // b = 8 ancora

Il valore 3 di a è stato sovrascritto: è perso per sempre.

Serve un terzo bicchiere

aux = a;  // aux = 3
a = b;    // a = 8
b = aux;  // b = 3

La variabile di appoggio aux salva il valore prima di perderlo.

Analogia: due bicchieri, uno di succo e uno d'acqua; per scambiare i contenuti serve un terzo bicchiere vuoto. Far provare a voce prima di mostrare la soluzione. Lo scambio sarà fondamentale nella UDA 7 per ordinare i vettori.

Puzzle

Rimetti in ordine il programma dello scambio

  1. int a = 3, b = 8, aux;
  2. aux = a;
  3. a = b;
  4. b = aux;
  5. printf("a=%d b=%d\n", a, b);
  6. return 0;
Unico ordine che funziona con queste righe: dichiarazione, aux = a, a = b, b = aux, stampa, return. Se si mette a = b prima di aux = a, alla fine entrambe valgono 8. Far verificare l'ordine scelto con una tabella di traccia.

Al computer · 15 minuti

Lo scambio, in C e in C++

  1. Scrivi in C il programma dello scambio con a = 3 e b = 8.
  2. Stampa i valori prima e dopo lo scambio.
  3. Prova la versione sbagliata (senza aux) e guarda cosa succede.
  4. Riscrivi la versione giusta in C++ con cout.
  5. Salva come scambio-cognome.cpp.
Controllo:
Prima: a=3 b=8
Dopo: a=8 b=3
La versione senza aux stampa a=8 b=8.
Soluzione C++: int a = 3, b = 8, aux; cout << "Prima: a=" << a << " b=" << b << endl; aux = a; a = b; b = aux; cout << "Dopo: a=" << a << " b=" << b << endl; Sfida per i più veloci: scambiare tre variabili a, b, c "in giro" (a prende b, b prende c, c prende a) con una sola aux.
