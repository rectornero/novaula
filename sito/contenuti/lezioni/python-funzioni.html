Le funzioni in Python

Crea la tua funzione con def

def saluta(nome):
    print("Ciao", nome + "!")

saluta("Ada")
saluta("Alan")

Le parole giuste

  • definizione: def, nome, parametri, due punti
  • corpo: le righe rientrate
  • parametro: nome
  • chiamata: saluta("Ada")
  • argomento: "Ada"
Definire una funzione non la esegue: il corpo parte solo quando la chiami.
Output: Ciao Ada! e Ciao Alan!. È la scomposizione del problema vista nella UDA 7: un compito grande diviso in sottoprogrammi. In C si scriveva void saluta(char nome[]) con i tipi; in Python niente tipi e niente graffe. I nomi delle funzioni si scrivono in minuscolo con il trattino basso: area_rettangolo, non AreaRettangolo.

Restituire un valore

return: la funzione ti dà indietro un risultato

def area_rettangolo(base, altezza):
    return base * altezza

a = area_rettangolo(3, 4)
print(a)                          # 12
print(area_rettangolo(5, 2) + 1)  # 11

return

consegna il valore a chi ha chiamato, che può salvarlo o usarlo in un calcolo

print

mostra sullo schermo, ma il valore poi è perso per il programma

La chiamata area_rettangolo(5, 2) viene sostituita dal valore 10, quindi + 1 dà 11. return fa anche uscire subito dalla funzione: le righe dopo return non vengono eseguite. Regola pratica: le funzioni che calcolano devono restituire con return; a stampare ci pensa il programma principale.

Quiz a trabocchetto

Che cosa compare sullo schermo?

def doppio(x):
    print(x * 2)

y = doppio(5)
print(y)
  1. 10 e poi 10
  2. 10 e poi None
  3. Solo 10
  4. Un errore

La funzione stampa 10, ma non ha return: restituisce il valore speciale None. Così y vale None e la seconda print lo mostra.

È la confusione più frequente tra print e return. La A è la risposta di chi pensa che "stampare" e "restituire" siano la stessa cosa. None in Python significa "nessun valore". Correzione: return x * 2 al posto di print(x * 2); allora compare un solo 10, dalla print finale.

  2. Definisci e_pari(n) che restituisce True o False.
  3. Sotto le definizioni, chiama le funzioni con print(…) e controlla i risultati.

Controllo: perimetro_quadrato(5) dà 20, area_quadrato(5) dà 25, e_pari(7) dà False, e_pari(10) dà True.
Soluzione: def perimetro_quadrato(lato): return 4 * lato def area_quadrato(lato): return lato * lato def e_pari(n): return n % 2 == 0 print(perimetro_quadrato(5), area_quadrato(5), e_pari(7), e_pari(10)) e_pari può restituire direttamente il confronto, senza if: n % 2 == 0 è già True o False. Chi scrive if n % 2 == 0: return True else: return False fa la cosa giusta in modo più lungo. Dopo l'esecuzione con F5 le funzioni restano disponibili nella shell: si può scrivere area_quadrato(12).

Puzzle

Che cosa succede quando scrivi a = area_rettangolo(3, 4)?

  1. Python incontra la chiamata e sospende la riga
  2. Copia 3 e 4 nei parametri base e altezza
  3. Esegue il corpo della funzione
  4. return calcola 12 ed esce dalla funzione
  5. Torna al punto in cui era stata fatta la chiamata
  6. Il valore 12 viene assegnato ad a
Ordine corretto come nella lista. È il "salto e ritorno" visto in C nella UDA 7. Alcuni mettono l'assegnazione ad a prima del ritorno: a non esiste finché la funzione non ha consegnato il risultato. A coppie, 2 minuti.

La visibilità delle variabili

Ciò che nasce nella funzione resta nella funzione

def prova():
    x = 5          # x locale
    print("dentro:", x)

x = 1              # x globale
prova()
print("fuori:", x)
  • Le variabili create in una funzione, parametri compresi, sono locali: esistono solo lì
  • Le variabili del programma principale sono globali
  • Due variabili con lo stesso nome possono convivere
  • Una funzione si può chiamare solo dopo il suo def

Output: dentro: 5 e poi fuori: 1.

Analogia: due studenti di nome Luca in due classi diverse; dentro la classe "Luca" indica quello presente. La x della funzione è un'altra variabile rispetto alla x globale. Esiste la parola chiave global per modificare una variabile globale da dentro una funzione, ma va evitata: meglio passare i dati con i parametri e restituirli con return. Visibilità delle funzioni: se si chiama prova() prima del def, Python dà NameError, perché legge il file dall'alto in basso.

Quiz

Che cosa stampa questo programma?

def aggiungi(n):
    n = n + 1
    return n

a = 5
aggiungi(a)
print(a)
  1. 6
  2. None
  3. Un errore
  4. 5

La funzione lavora su n, una copia locale: a resta 5. In più il valore restituito (6) non viene salvato da nessuna parte. Serviva a = aggiungi(a).

Errore doppio molto comune: credere che la funzione modifichi a e dimenticare di usare il valore restituito. Collegamento con il passaggio per valore in C (UDA 7): anche lì la funzione riceveva una copia. Chi risponde B confonde con il quiz precedente: qui il return c'è.

Al computer · 15 minuti

Il convertitore di temperature

  1. Nuovo file temperature.py. Definisci celsius_a_fahrenheit(c) che restituisce c * 9 / 5 + 32.
  2. Con un for c in range(-10, 41, 10): stampa una tabella con i gradi Celsius e Fahrenheit.
  3. Aggiungi fahrenheit_a_celsius(f), cioè la formula inversa, e verificala.
Controllo: 0 °C = 32.0 °F, 30 °C = 86.0 °F, 100 °C = 212.0 °F. Curiosità: a -40 i due valori coincidono.
Soluzione: def celsius_a_fahrenheit(c): return c * 9 / 5 + 32 def fahrenheit_a_celsius(f): return (f - 32) * 5 / 9 for c in range(-10, 41, 10): print(c, "°C =", celsius_a_fahrenheit(c), "°F") La tabella: -10 → 14.0, 0 → 32.0, 10 → 50.0, 20 → 68.0, 30 → 86.0, 40 → 104.0. Verifica dell'inversa: fahrenheit_a_celsius(212) dà 100.0. Errore tipico: dimenticare le parentesi in (f - 32).

Il punto di ingresso

Da dove parte il programma? Da main

def saluta(nome):
    print("Ciao", nome)

def main():
    nome = input("Nome? ")
    saluta(nome)

if __name__ == "__main__":
    main()

In C il programma parte sempre da main(). In Python si usa la stessa idea per ordine: prima tutte le funzioni, poi un'unica chiamata a main().

__name__ vale "__main__" quando esegui il file con F5. Se un altro programma lo importa per usarne le funzioni, main() non parte.

Il doppio trattino basso si legge "dunder" (double underscore). Non serve capire ogni dettaglio: è una formula fissa da copiare in fondo ai programmi. Vantaggio pratico: il file diventa un modulo riutilizzabile, come random o math. Esempio da mostrare: in un altro file nella stessa cartella, import nomefile e poi nomefile.saluta("Ada").

Al computer · 20 minuti

Un programma fatto a mattoncini

  1. File voti-funzioni.py. Scrivi leggi_voto(): chiede un voto e, con un while, lo richiede finché non è tra 1 e 10. Poi lo restituisce.
  2. Scrivi giudizio(voto): restituisce "sufficiente" o "insufficiente".
  3. Scrivi main(): legge un voto e stampa il giudizio.
  4. In fondo: if __name__ == "__main__": e, rientrato, main().
Controllo: scrivendo 12 e poi 7 il programma chiede di riprovare e poi stampa Il voto 7.0 è sufficiente. Nessuna funzione deve contenere print tranne main.
Soluzione: def leggi_voto(): voto = float(input("Voto (1-10): ")) while voto < 1 or voto > 10: voto = float(input("Non valido, riprova: ")) return voto def giudizio(voto): if voto >= 6: return "sufficiente" else: return "insufficiente" def main(): v = leggi_voto() print("Il voto", v, "è", giudizio(v)) if __name__ == "__main__": main() Riunisce tutta la UDA: input, selezione, while, funzioni. Chi finisce prima: main che legge 3 voti con un for e stampa la media, riusando leggi_voto().
