Unità 4 · Il WWW e le pagine web

Lo stile della
pagina web: i CSS

Stesso HTML, mille vestiti diversi. Colori in esadecimale, caratteri, bordi ed elenchi: oggi la tua pagina smette di sembrare quella del 1991.

Obiettivi: capire la separazione tra contenuto (HTML) e presentazione (CSS); scrivere regole con selettore, proprietà e valore; collegare i CSS in tre modi e preferire il file esterno; usare i selettori di tipo e il raggruppamento; esprimere i colori con nomi, esadecimale e rgb(); usare le proprietà per testo, font, sfondi, bordi, elenchi e tabelle; validare con il CSS Validator del W3C. Classi, id, pseudo-classi e specificità arrivano nella lezione successiva. Durata: 2 ore. Serve la cartella web-cognome delle lezioni precedenti.

Oggi

Un modello di AI che legge immagini può trasformare lo schizzo di una pagina, fatto a mano su un foglio, in HTML e CSS funzionanti. La divisione dei compiti però resta la stessa: per correggere quel codice bisogna sapere che cosa fa ogni regola.

Esempio storico: il CSS Zen Garden (csszengarden.com, Dave Shea, 2003) usa un unico file HTML e centinaia di fogli di stile diversi creati da designer di tutto il mondo: far vedere due o tre design alla LIM. Separare porta vantaggi concreti: un solo file CSS cambia l'aspetto di tutte le pagine del sito; lo stesso HTML si adatta a telefono, stampa, schermo grande. La generazione di codice da uno schizzo è stata mostrata pubblicamente nel 2023 con i modelli multimodali: il risultato va sempre controllato.

Menti che ci hanno preceduto

1994: un foglio di stile "a cascata"

Il 10 ottobre 1994 Håkon Wium Lie, un ricercatore norvegese che lavorava al CERN con Berners-Lee, pubblica la proposta Cascading HTML style sheets. Con Bert Bos la trasforma nello standard CSS1, raccomandazione del W3C nel dicembre 1996.

"A cascata" perché più fogli di stile (dell'autore, del browser, del lettore) si sommano uno sull'altro.

Traduzione: "Questo è per tutti". Berners-Lee comparve alla cerimonia del 27 luglio 2012 a un computer NeXT e la frase, pubblicata anche come suo tweet, venne scritta con le luci sulle tribune. Collegamento con i CSS: separare lo stile permette a ognuno di adattare la pagina (ingrandire il testo, alto contrasto, modalità scura) senza toccare il contenuto. Prima dei CSS i designer usavano tag come <font> e tabelle per impaginare, mescolando contenuto e aspetto. Lie divenne poi CTO di Opera Software.

La sintassi

Anatomia di una regola CSS

una regolah1 { color: #d0541f; font-size: 48px; }

Selettore

h1: a quali elementi si applica

Proprietà

color: che cosa cambio

Valore

#d0541f: come lo cambio

Dichiarazione

proprietà: valore; dentro le graffe

Più selettori insieme con la virgola: h1, h2, h3 { font-family: Georgia, serif; }. Commenti: /* così */.

Errori tipici: dimenticare il punto e virgola (la dichiarazione successiva si rompe), usare = al posto dei due punti, scrivere i valori tra virgolette (color: "red" non funziona). Il raggruppamento con la virgola evita di ripetere le stesse regole. Le graffe si scrivono con AltGr+Shift+è e AltGr+Shift++ sulla tastiera italiana (o AltGr+7 e AltGr+0 su alcune tastiere): mostrarlo, perché blocca molti studenti.

Dove si scrivono

Tre modi per collegare i CSS

In linea

<p style="color:red">

Vale per un solo elemento. Da evitare: stile e contenuto di nuovo mescolati.

Interno

<style>
  p { color: red; }
</style>

Nel head. Vale per una sola pagina.

Esterno

<link rel="stylesheet"
  href="stile.css">

Nel head. Un file per tutto il sito, scaricato una volta e tenuto in cache.

Il foglio esterno è la scelta giusta per un sito: si cambia un file e cambiano tutte le pagine; il browser lo scarica una volta (si vede nella scheda Network: tipo "stylesheet", e al secondo caricamento dalla cache). Lo stile in linea vince sulle altre regole: ne parleremo con la specificità nella prossima lezione. Il file .css contiene solo regole, senza tag HTML e senza <style>: errore frequente.

Al computer · 15 minuti

Prime regole dal vivo su CodePen

  1. Apri codepen.io/pen (senza account). Nel riquadro HTML incolla il body della tua hobby.html.
  2. Nel riquadro CSS scrivi una regola per body: font-family, background-color chiaro, color scuro.
  3. Aggiungi una regola per h1 con un colore e text-align: center.
  4. Aggiungi p { line-height: 1.6; } e guarda come respira il testo.
  5. Cambia un valore alla volta e osserva l'anteprima.
Controllo: l'anteprima cambia mentre scrivi; il titolo è centrato e colorato; tutto il testo usa il nuovo carattere perché lo eredita dal body. Copia le regole nel Blocco note: serviranno tra poco.
Ereditarietà: color, font-family e line-height passano dal body a tutti i figli; bordi e sfondi no. Le immagini con percorso relativo non si vedranno in CodePen (non c'è la cartella img): è normale. Se CodePen è bloccato, jsfiddle.net ha i riquadri HTML e CSS allo stesso modo. Soluzione di esempio: body { font-family: Verdana, Arial, sans-serif; background-color: #fdf6ee; color: #222; } h1 { color: #d0541f; text-align: center; }

È il colore di questa lezione. Ripassa la conversione con la lezione sull'esadecimale: ogni coppia è una luce da 0 a 255.

Collegamento diretto alla lezione esadecimale già svolta dalla 3E. Ogni canale ha 256 valori (1 byte): 256³ = 16 777 216 colori. Nel formato corto ogni cifra viene raddoppiata: #f80 = #ff8800. Il selettore di colore dei DevTools (clic sul quadratino accanto a un colore nella scheda Styles) converte tra i formati: farlo vedere. Esistono anche hsl() e i colori con trasparenza (rgb(208 84 31 / 50%)), non necessari ora.

Quiz a trabocchetto

Quale di questi NON è rosso puro?

  1. red
  2. #f00
  3. rgb(255, 0, 0)
  4. #ff000

#ff000 ha cinque cifre: non è un colore valido e il browser ignora la dichiarazione. #f00 invece è la forma corta di #ff0000, quindi è rosso puro come red e rgb(255, 0, 0).

La B è il tranello: sembra "incompleto" ma è valido. Il CSS accetta 3, 4, 6 oppure 8 cifre esadecimali (4 e 8 includono la trasparenza). Con 5 cifre la dichiarazione è scartata e il testo resta del colore ereditato: nessun messaggio d'errore, si vede solo nei DevTools (dichiarazione barrata con un'icona di avviso) o nel validatore.

Le proprietà che userai di più

font-family: il browser usa il primo carattere che trova installato; l'ultima voce è sempre una famiglia generica (serif, sans-serif, monospace) come rete di sicurezza. I nomi con spazi vanno tra virgolette. Unità: px assoluti; em relativi alla dimensione del genitore; rem relativi all'elemento radice html (di solito 16px, quindi 2rem = 32px). rem rispetta l'ingrandimento scelto dall'utente nelle impostazioni del browser. Togliere la sottolineatura ai link è legittimo solo se restano riconoscibili in altro modo.

Al computer · 15 minuti

Un foglio di stile per tutto il sito

  1. Nella cartella web-cognome crea con il Blocco note il file stile.css (tipo Tutti i file, UTF-8) e incolla le regole di CodePen.
  2. Nel head di index.html e di hobby.html aggiungi <link rel="stylesheet" href="stile.css">.
  3. Aggiungi regole per h2 e per a (colore a tua scelta, in esadecimale).
  4. Apri le due pagine nel browser, poi cambia il colore di h1 in stile.css, salva e ricarica.
Controllo: una sola modifica in stile.css cambia entrambe le pagine. Se una pagina resta senza stile, controlla il nome del file e il percorso nel link (in pagine/orario.html serve ../stile.css).
Errori tipici: file salvato come stile.css.txt; tag <style> scritto dentro il file .css; link messo nel body invece che nel head (funziona, ma non è corretto). Con F12 › Network si vede la richiesta di stile.css: se è rossa con 404 (o "failed" per i file locali) il percorso è sbagliato. Chi finisce prima collega stile.css anche a pagine/orario.html.

Mettiti alla prova

Nel CSS scrivi p { colour: red; }. Che cosa succede?

  1. Il testo diventa rosso lo stesso
  2. Il browser blocca tutto il foglio di stile
  3. Il browser ignora solo quella dichiarazione
  4. La pagina compare bianca

colour (all'inglese britannico) non è una proprietà CSS: il browser salta la dichiarazione che non capisce e applica tutte le altre. Nessun avviso a schermo: l'errore si trova con i DevTools o con il validatore.

Come per l'HTML, anche i CSS sono tolleranti: è una scelta di progetto, così un browser vecchio ignora le proprietà nuove che non conosce senza rompere la pagina. Il rovescio: gli errori di battitura passano inosservati. Nei DevTools la dichiarazione compare barrata con un triangolo giallo "Unknown property name".

Al computer · 15 minuti

L'orario con stile, poi il validatore

  1. In pagine/orario.html togli border="1" e collega ../stile.css.
  2. In stile.css scrivi le regole per table, th e td della slide precedente.
  3. Premi F12, scheda Elements, seleziona un th: in Styles cambia il colore di sfondo dal vivo.
  4. Apri jigsaw.w3.org/css-validator, scheda By direct input, incolla stile.css e premi Check.
  5. Aggiungi apposta colour: red;, ricontrolla e leggi l'errore. Poi toglilo.
Controllo: bordi singoli e intestazioni colorate; la modifica nei DevTools sparisce quando ricarichi (è solo una prova); il validatore dice "Congratulations! No Error Found" e con colour segnala "Property colour doesn't exist".
Il messaggio esatto del validatore CSS può variare leggermente; il senso è "la proprietà colour non esiste". Ora anche il validatore HTML non segnala più border come obsoleto. I DevTools sono il laboratorio migliore per sperimentare: si copia nel file solo ciò che funziona. Se jigsaw è lento o bloccato, basta il controllo nei DevTools (dichiarazione barrata).

Lo stesso contenuto, più vestiti

La modalità scura è un foglio di stile

body { background-color: #ffffff;
       color: #172033; }

/* se il telefono è in modalità scura */
@media (prefers-color-scheme: dark) {
  body { background-color: #141c30;
         color: #eef1f8; }
}

Oggi

Quando metti il telefono in modalità scura, molti siti cambiano colore da soli: non hanno un secondo HTML, hanno qualche regola CSS in più che legge la tua preferenza. È la promessa del 1994 ancora al lavoro: il contenuto resta, l'aspetto si adatta a chi legge.

La media query prefers-color-scheme è supportata da tutti i browser principali dal 2019-2020, quando iOS 13 e Android 10 hanno introdotto la modalità scura di sistema. Le media query le vedranno meglio nell'Unità 5 (responsive). Prova facoltativa: nei DevTools, menu Rendering, "Emulate CSS media feature prefers-color-scheme". Domanda: "Che cosa deve restare uguale in modalità scura?" Il contrasto tra testo e sfondo.
