Sottoprogrammi e funzioni

Due tipi di sottoprogramma

Funzione

Fa un calcolo e restituisce un valore a chi l'ha chiamata.

Come =MEDIA(B2:B8) in Calc: le dai dei dati, ti torna un numero.

Procedura

Esegue delle azioni e non restituisce niente.

In C è una funzione di tipo void ("vuoto"), per esempio una che disegna una cornice.

Gira le carte: funzione o procedura?

Calcola l'area di un rettangolo

Funzione: restituisce un numero, l'area.

Stampa il menu del gioco

Procedura: scrive sullo schermo, non restituisce niente.

Dice se un numero è pari

Funzione: restituisce 1 (vero) o 0 (falso).

In C tecnicamente sono tutte "funzioni": la procedura è una funzione con tipo di ritorno void. Il libro usa entrambi i nomi. Per ogni carta chiedere prima la risposta per alzata di mano. La terza è la più discussa: "dire" sembra stampare, ma una funzione ben fatta restituisce il valore e lascia a main la decisione di cosa stampare.

Le funzioni in C

Com'è fatta una funzione

int quadrato(int n)  // intestazione
{
    int q = n * n;     // corpo
    return q;          // risultato
}

// chiamata, per esempio nel main:
int r = quadrato(5);  // r vale 25
  • Tipo di ritorno: int, il tipo del valore restituito
  • Nome: quadrato, scelto da te
  • Parametri: int n, i dati in ingresso
  • Corpo: le istruzioni tra graffe
  • return: restituisce il valore ed esce subito
Far leggere ad alta voce l'intestazione: "quadrato è una funzione che riceve un intero n e restituisce un intero". Nella chiamata quadrato(5) il 5 è l'argomento (parametro attuale), n è il parametro formale: il valore 5 viene copiato in n. Lo approfondiremo nella prossima lezione sul passaggio dei parametri.

Un programma con una funzione

Prototipo, main, definizione

#include <stdio.h>
int quadrato(int n);     // prototipo

int main() {
    int x;
    printf("Numero: ");
    scanf("%d", &x);
    printf("Quadrato: %d\n", quadrato(x));
    return 0;
}

int quadrato(int n) {   // definizione
    return n * n;
}

Il prototipo

È la "promessa" al compilatore: più sotto troverai una funzione con questo nome, questi parametri e questo tipo.

Senza prototipo, la funzione va scritta prima del main.
Il compilatore legge il file dall'alto in basso: se in main incontra quadrato senza averlo mai visto, segnala un errore o un avviso. Due soluzioni equivalenti: prototipo in alto e definizione in fondo, oppure definizione prima del main. Con input 7 il programma stampa "Quadrato: 49". Nei prossimi esempi, per risparmiare spazio, scriveremo spesso le funzioni prima del main.

Al computer · 15 minuti

La tua prima procedura: una cornice

  1. Apri onlinegdb.com (o l'IDE della scuola) e scegli il linguaggio C.
  2. Scrivi la procedura void linea(int n) che con un ciclo for stampa n asterischi e poi va a capo.
  3. Nel main chiama linea(10), poi stampa CIAO!, poi di nuovo linea(10).
  4. Esegui, poi prova con linea(20): quante righe hai dovuto cambiare?
  5. Salva il file come cornice.c.
Controllo: l'output è
**********
CIAO!
**********
Il ciclo for è scritto una volta sola, dentro la procedura.
Soluzione: void linea(int n) { for (int i = 0; i < n; i++) printf("*"); printf("\n"); } int main() { linea(10); printf(" CIAO!\n"); linea(10); return 0; } Per chi finisce prima: aggiungere un secondo parametro char c, linea(int n, char c), e stampare con printf("%c", c), così da disegnare la cornice con il carattere scelto. Su OnlineGDB per salvare serve un account: in alternativa copiare il codice in un file di testo cornice.c con il Blocco note.

Puzzle

Che cosa succede quando main chiama quadrato(x)?

  1. Il main arriva all'istruzione che contiene quadrato(x)
  2. Il valore di x viene copiato nel parametro n
  3. L'esecuzione salta alla prima istruzione della funzione
  4. La funzione calcola n * n
  5. return restituisce il risultato e chiude la funzione
  6. Il main riprende dal punto della chiamata e usa il valore
Ordine giusto come scritto. Errore tipico: mettere il salto alla funzione prima della copia del valore. In realtà i valori dei parametri vengono preparati al momento della chiamata, prima di entrare nel corpo. Far fare il puzzle a squadre di 3 con il timer mentale di 2 minuti, poi un portavoce spiega l'ordine.

Quiz a trabocchetto

Che cosa stampa questo programma?

int doppio(int n) {
    printf("%d ", n * 2);
    return n * 2;
}
int main() {
    int a = doppio(3);
    printf("%d", doppio(a));
    return 0;
}
  1. 6 12
  2. 6 12 12
  3. 12
  4. 6 6 12

doppio(3) stampa "6 " e restituisce 6. Poi doppio(6) stampa "12 " e restituisce 12, che il main stampa: 6 12 12.

Programma verificato con gcc: stampa "6 12 12". Il trabocchetto è dimenticare che anche la funzione stampa: chi risponde A pensa solo ai valori restituiti. Morale: una funzione che calcola di solito non dovrebbe stampare; meglio restituire e lasciare la stampa al main.

Chi crea un'intelligenza artificiale non riparte da zero: usa librerie come PyTorch, enormi raccolte di funzioni già pronte per fare i calcoli delle reti neurali. È la stessa idea di Kernighan e Ritchie.

Storia da raccontare: le prime "subroutine" nascono nel 1949-51 a Cambridge sul calcolatore EDSAC; David Wheeler inventò il modo di saltare a un sottoprogramma e tornare indietro, e nel 1951 Wilkes, Wheeler e Gill pubblicarono il primo libro con una libreria di sottoprogrammi pronti.

Le funzioni in C++

Stessa funzione, input e output diversi

C

#include <stdio.h>

int massimo(int a, int b) {
    if (a > b) return a;
    return b;
}
int main() {
    printf("%d\n", massimo(4, 9));
    return 0;
}

C++

#include <iostream>
using namespace std;
int massimo(int a, int b) {
    if (a > b) return a;
    return b;
}
int main() {
    cout << massimo(4, 9) << endl;
    return 0;
}

La funzione evidenziata è identica: cambiano solo la libreria e il modo di scrivere sullo schermo.

Entrambi i programmi stampano 9 (verificati con gcc e g++). Ricordare la differenza vista nella UDA 6: in C si usa printf/scanf con stdio.h, in C++ cout/cin con iostream. In C++ i file hanno estensione .cpp. Domanda: perché massimo ha due return? Perché il primo che viene eseguito chiude la funzione.

Il massimo di tre numeri, in C++

  1. Su OnlineGDB scegli il linguaggio C++.
  2. Scrivi la funzione int massimo(int a, int b) della slide precedente.
  3. Nel main leggi tre numeri con cin.
  4. Trova il massimo dei tre chiamando due volte massimo, senza scrivere altri if.
  5. Stampa il risultato con cout. Salva come massimo3.cpp.
Controllo: con 4 9 2 stampa 9; con -5 -2 -8 stampa -2. Il trucco è una chiamata dentro l'altra.
Soluzione: int m = massimo(massimo(a, b), c); cout << "Il massimo e' " << m << endl; Verificato con g++. Il caso con numeri negativi smaschera chi inizializza il massimo a 0. Per chi finisce prima: scrivere anche int minimo(int a, int b) e stampare il minimo dei tre.

Quiz

Che cosa stampa printf("%d", massimo(4, 9))?

int massimo(int a, int b) {
    if (a > b) return a;
    return b;
    printf("fine");
}
  1. 9fine
  2. 4
  3. 9
  4. fine9

return b restituisce 9 e chiude subito la funzione: la printf("fine") non viene mai eseguita.

Verificato con gcc: stampa 9. Misconcezione classica: pensare che return "salvi" il valore e poi la funzione continui. Il codice dopo un return che viene sempre eseguito si chiama codice irraggiungibile: alcuni compilatori e IDE lo segnalano con un avviso.

Funzioni già pronte: le librerie

Abbina la funzione a quello che fa

sqrt(x) · math.h
Radice quadrata di x
pow(b, e) · math.h
b elevato alla potenza e
abs(n) · stdlib.h
Valore assoluto di un intero: abs(-7) vale 7
rand() · stdlib.h
Un numero intero pseudocasuale
printf(...) · stdio.h
Scrive testo e numeri sullo schermo
Tutte queste sono funzioni scritte da altri e raccolte in librerie: per usarle basta il #include giusto. rand() l'avete già usata nella UDA 6 per i numeri casuali. Domanda: quale di queste è in realtà quasi una procedura? printf restituisce il numero di caratteri scritti, ma di solito quel valore si ignora.

Un esempio completo

Il programma Pagella, pezzo per pezzo

#include <stdio.h>
float media(float a, float b, float c) {
    return (a + b + c) / 3;
}
void giudizio(float m) {
    if (m >= 6) printf("Sufficiente\n");
    else printf("Da recuperare\n");
}
int main() {
    float v1, v2, v3;
    printf("Tre voti: ");
    scanf("%f %f %f", &v1, &v2, &v3);
    float m = media(v1, v2, v3);
    printf("Media: %.2f\n", m);
    giudizio(m);
    return 0;
}

1 · Leggi i voti

Lo fa il main con scanf.

2 · media

Funzione: restituisce un float.

3 · giudizio

Procedura void: stampa e basta.

Il main si legge come lo schema top-down.

Riprende lo schema top-down della slide 3. Con 5 6,5 7 stampa "Media: 6.17" e "Sufficiente"; con 5 5,5 6 stampa "Media: 5.50" e "Da recuperare" (verificato con gcc). Attenzione: nella console i decimali si scrivono con il punto (6.5). Domanda: perché /3 e non /3.0? Perché a+b+c è già float, quindi la divisione è decimale; con tre int servirebbe /3.0.

Al computer · 20 minuti

Il convertitore di temperature

  1. In C scrivi la funzione float fahrenheit(float c) che restituisce c * 9 / 5 + 32.
  2. Scrivi la procedura void tabella(): con un for da 0 a 100, passo 20, stampa i gradi Celsius e i Fahrenheit corrispondenti.
  3. Il main deve contenere solo la chiamata tabella(); e return 0;.
  4. Salva come temperature.c.
Controllo: la tabella ha 6 righe, da 0 C = 32.0 F a 100 C = 212.0 F. A metà trovi 40 C = 104.0 F.
Soluzione: float fahrenheit(float c) { return c * 9 / 5 + 32; } void tabella() { for (int c = 0; c <= 100; c += 20) printf("%d C = %.1f F\n", c, fahrenheit(c)); } Righe attese: 0→32.0, 20→68.0, 40→104.0, 60→140.0, 80→176.0, 100→212.0 (verificato con gcc). Il simbolo dei gradi può dare problemi nella console di Windows: per questo si scrive solo C e F. Per chi finisce prima: aggiungere la funzione inversa float celsius(float f).

Risposta

Oggi

Gli assistenti AI possono usare funzioni scritte da programmatori (si chiama function calling): il modello decide quale funzione chiamare e con quali parametri, il programma la esegue e il risultato torna al modello, che scrive la risposta.

Esempio illustrativo: i dati del meteo sono inventati per l'esempio. È così che un assistente può dare informazioni aggiornate o fare azioni (impostare una sveglia): il modello linguistico da solo non conosce il meteo di domani, ma sa "chiamare" una funzione che lo recupera. Collegamento: i parametri devono essere del tipo giusto, proprio come in C. Domanda: che cosa succederebbe se il modello sbagliasse il parametro e scrivesse "Bali"?
