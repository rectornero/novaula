La selezione semplice e doppia in C e C++: condizioni, operatori logici, blocchi di istruzioni e l'arte di non fidarsi mai dell'input.

Obiettivi: scrivere selezioni semplici e doppie con if ed else, usare gli operatori di confronto e gli operatori logici, delimitare i blocchi con le graffe, controllare i dati in input. Collegamento con la UDA 5: il rombo dei flow chart e la selezione in Flowgorithm. Durata indicativa: 2-3 ore.

Percorsi alternativi

Dal rombo del flow chart all'if

if (voto >= 6) {
    printf("Promosso\n");
} else {
    printf("Insufficiente\n");
}

La condizione va sempre tra parentesi tonde. Se è vera si esegue il primo blocco, altrimenti (else) il secondo.

Mostrare la corrispondenza: rombo = if, ramo V = primo blocco, ramo F = else. Chi ha usato Flowgorithm ritrova la stessa struttura. In C++ cambia solo l'istruzione di stampa: la sintassi di if ed else è identica.

Semplice e doppia

Con o senza else?

Selezione semplice

Se la condizione è vera fa qualcosa; se è falsa non fa niente e prosegue.

if (febbre > 37.5) {
    printf("Resta a casa\n");
}

Selezione doppia

Due strade: una se la condizione è vera, l'altra se è falsa. Sempre una delle due.

if (n % 2 == 0) {
    printf("pari\n");
} else {
    printf("dispari\n");
}
Far inventare a voce un esempio per tipo. Semplice: "se ho finito i giga, avvisami". Doppia: "se la batteria è sotto il 20% luce rossa, altrimenti verde". Il test n % 2 == 0 riprende l'operatore resto della lezione precedente.

Gli operatori di confronto

OperatoreSignificaEsempio vero
==uguale a5 == 5
!=diverso da5 != 3
< >minore, maggiore3 < 5
<= >=minore o uguale, maggiore o uguale6 >= 6
Attenzione!
= mette un valore nella variabile.
== confronta due valori.
Confonderli è l'errore più famoso del C.
Una condizione in C vale 1 se è vera e 0 se è falsa; più in generale, qualsiasi valore diverso da 0 conta come vero. Questo spiega il quiz che segue. Far leggere ad alta voce: "doppio uguale si legge: è uguale a?".

Quiz a trabocchetto

Che cosa stampa questo programma?

int x = 3;
if (x = 5) printf("cinque"); else printf("non cinque");
  1. non cinque
  2. Niente
  3. Errore di compilazione
  4. cinque

x = 5 non confronta: mette 5 in x. Il valore dell'assegnazione è 5, che è diverso da 0, quindi per il C è vero. Si stampa "cinque" e intanto x è stato cambiato!

Quasi tutti rispondono "non cinque" (pensano a un confronto) o "errore". Verificato con gcc: compila e stampa cinque; con l'opzione -Wall compare solo un avviso ("suggest parentheses around assignment used as truth value"). Morale: leggere sempre gli avvisi del compilatore.

Al computer · 15 minuti

Pari o dispari?

  1. Su OnlineGDB (o nell'IDE della scuola) scrivi in C un programma che chiede un numero intero.
  2. Con if (n % 2 == 0) stampa che è pari, altrimenti (else) che è dispari.
  3. Provalo con 14, 7, 0 e -3.
  4. Salva come pari-dispari-cognome.c.
Controllo:
14 e' pari
7 e' dispari
0 e' pari
-3 e' dispari
Soluzione: int n; printf("Scrivi un numero intero: "); scanf("%d", &n); if (n % 2 == 0) { printf("%d e' pari\n", n); } else { printf("%d e' dispari\n", n); } Approfondimento: chi scrive if (n % 2 == 1) sbaglia con i negativi, perché in C -3 % 2 vale -1. Il test con == 0 funziona sempre. Uscite verificate con gcc.

Blocchi di istruzioni

Le graffe decidono che cosa sta dentro l'if

Senza graffe

if (voto < 6)
    printf("Insufficiente\n");
    printf("Studia di piu'!\n");

Nell'if c'è solo la prima istruzione. "Studia di più!" esce sempre, anche con 8.

Con le graffe

if (voto < 6) {
    printf("Insufficiente\n");
    printf("Studia di piu'!\n");
}

Le due istruzioni formano un blocco: si eseguono insieme o per niente.

Il rientro (indentazione) serve agli umani, il compilatore lo ignora: conta solo dove sono le graffe. Regola del corso: mettere SEMPRE le graffe, anche con una sola istruzione. Altro tranello da mostrare: if (voto < 6); con il punto e virgola dopo la parentesi, l'if non controlla più niente. Verificato con gcc: la versione senza graffe stampa "Studia di piu'!" anche con voto 8.

Gli operatori logici

Due condizioni insieme: e, o, non

&&

AND, "e"

Vero solo se tutte e due sono vere.

eta >= 14 && eta <= 18

||

OR, "o"

Vero se almeno una è vera.

eta < 12 || eta >= 65

!

NOT, "non"

Inverte: il vero diventa falso e viceversa.

!(voto >= 6)

Sono gli stessi connettivi della logica che hai visto nella UDA 1, scritti con i simboli del C.
Il simbolo | si ottiene sulla tastiera italiana con il tasto a sinistra dell'1 insieme a Maiusc. Far tradurre a voce: "eta tra 14 e 18 compresi", "bambino o anziano", "non sufficiente". !(voto >= 6) equivale a voto < 6.

Mettiti alla prova

Vogliamo sapere se eta è tra 14 e 18. Quale condizione è giusta?

  1. 14 <= eta <= 18
  2. eta >= 14 || eta <= 18
  3. eta >= 14 && eta <= 18
  4. eta >= 14 && <= 18

Servono due confronti completi uniti da &&. La A si scrive così in matematica, ma in C vale sempre vero: prima calcola 14 <= eta (0 o 1) e poi confronta quel risultato con 18. La B è vera per qualsiasi età. La D non compila.

La A è il tranello: compila, e con eta = 40 la condizione risulta vera. Verificato con gcc, che con -Wall avvisa: "comparisons like 'X<=Y<=Z' do not have their mathematical meaning". Far trovare un'età per cui la B è falsa: non esiste.

"; cin >> eta; if (eta < 12 || eta >= 65) { cout << "Biglietto ridotto: 5 euro" << endl; } else { cout << "Biglietto intero: 9 euro" << endl; } Insistere sui casi limite: sono quelli in cui si nascondono gli errori (< al posto di <=). Il controllo dei dati in input

Regola d'oro: non fidarti mai dell'utente

printf("Voto (da 1 a 10): ");
scanf("%d", &voto);
if (voto < 1 || voto > 10) {
    printf("Errore: voto non valido\n");
} else {
    printf("Voto registrato\n");
}
  • Un voto deve stare tra 1 e 10.
  • Un divisore non può essere 0.
  • Un'età non può essere negativa.

La divisione a prova di errore

  1. In C dichiara due float e leggi dividendo e divisore con scanf("%f", ...).
  2. Se il divisore è 0 stampa Impossibile dividere per zero!
  3. Altrimenti stampa il risultato con 2 decimali.
  4. Salva come divisione-cognome.c.
Controllo: 7 e 2 → Risultato: 3.50; 5 e 0 → Impossibile dividere per zero!; -9 e 4 → Risultato: -2.25.
Soluzione: float a, b; printf("Dividendo: "); scanf("%f", &a); printf("Divisore: "); scanf("%f", &b); if (b == 0) { printf("Impossibile dividere per zero!\n"); } else { printf("Risultato: %.2f\n", a / b); } Sfida: aggiungere il controllo del voto (1-10) della slide precedente in un altro programma. Uscite verificate con gcc.

Sfida finale

Apri il lucchetto: segui gli if a mano

  • 1ª cifra: a = 7; if (a > 5) a = a - 4; else a = a + 4;
  • 2ª cifra: b = 4; if (b % 2 == 0 && b > 5) b = 1; else b = 9;
  • 3ª cifra: c = 0; if (c == 0 || c > 100) c = 2;
  • 4ª cifra: d = 6; if (d != 6) d = 0;

Ogni cifra è il valore finale della variabile.

Lucchetto aperto! a = 3, b = 9 (4 non è maggiore di 5), c = 2, d resta 6.
Codice: 3926 (verificato con gcc). A squadre, solo carta e penna. Tranelli: la seconda riga (con && basta una condizione falsa) e la quarta (selezione semplice senza else: se la condizione è falsa la variabile non cambia).

Biglietto d'uscita

Completa prima di uscire

Per confrontare due valori si usa l'operatore , non il singolo uguale.

La parte che si esegue quando la condizione è falsa inizia con .

Per dire "tutte e due le condizioni sono vere" si usa .

Per raggruppare più istruzioni in un blocco si usano le parentesi .

Tre minuti. Soluzioni: ==, else, && (accettato anche "and"), graffe.
